Privacidad y datos

BARBERLINK

Información clara sobre tus datos

Esta sección explica qué información puede utilizar BARBERLINK, por qué se utiliza, con qué servicios puede procesarse y qué controles tienes sobre tu perfil.

1. ¿Qué datos utilizamos?

Dependiendo de las funciones que uses, podemos gestionar:

Nombre y apellido Celular Correo electrónico Fecha de nacimiento Reservas Servicio elegido Fecha y hora Notas de la reserva Puntos y nivel Estado de cuenta

Los datos de autenticación y las credenciales de acceso se gestionan mediante el sistema de autenticación configurado para BARBERLINK.

2. ¿Para qué se utilizan?

  • Crear, confirmar y administrar tus reservas.
  • Identificar tu cuenta y permitir el acceso mediante celular, correo u otros métodos habilitados.
  • Vincular reservas anteriores realizadas con el mismo número de celular.
  • Mostrar tu historial, visitas, puntos y recompensas.
  • Contactarte respecto de una reserva o de la atención solicitada.
  • Prevenir errores, abusos y problemas de seguridad.
  • Diagnosticar fallos técnicos cuando se utilicen herramientas de diagnóstico.

3. ¿Dónde se procesan?

La aplicación utiliza Supabase para autenticación, almacenamiento de datos y operaciones de la aplicación. Por ello, la información necesaria para esas funciones se transmite a la infraestructura configurada para el proyecto.

La aplicación también carga recursos externos, como la biblioteca de Supabase y fuentes web. Esos servicios pueden recibir información técnica necesaria para realizar las solicitudes correspondientes.

4. WhatsApp y comunicaciones

La interfaz informa que las confirmaciones pueden enviarse por WhatsApp. Cuando se utilice un proveedor de mensajería, el número y la información estrictamente necesaria para la comunicación podrán procesarse a través de ese servicio.

Esta pantalla no inventa un proveedor específico: debe identificarse aquí el proveedor real que el negocio utilice antes de publicar oficialmente esta política.

5. Huella / Passkey

Si activas el acceso con passkey, BARBERLINK solicita al dispositivo que realice la verificación biométrica mediante WebAuthn. La huella biométrica en sí no se introduce en el formulario de BARBERLINK. La aplicación recibe el resultado de autenticación y la credencial necesaria para el acceso.

6. Tú controlas tu perfil

Puedes revisar y solicitar la actualización de los datos editables desde Mi cuenta → Perfil → Editar perfil. Los datos necesarios para mantener una reserva o cumplir obligaciones aplicables pueden requerir tratamiento adicional o conservación durante el tiempo correspondiente.

7. Eliminación y solicitudes

Si quieres solicitar corrección, acceso o eliminación de información, utiliza el canal de contacto que el negocio publique para BARBERLINK. La eliminación de una cuenta no debe entenderse automáticamente como eliminación inmediata de información que sea necesaria para una reserva pendiente, comprobante, seguridad o cumplimiento legal.

8. Transparencia técnica

BARBERLINK registra en el navegador ciertos eventos técnicos de diagnóstico para ayudar a detectar errores. Estos registros no deben utilizarse como sustituto de una política de privacidad ni deben contener contraseñas, códigos OTP o datos biométricos.
